# Sameer — Portfolio Website

A responsive, static portfolio for Sameer, a BCA 3rd-semester student specializing in AI/ML.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser.

For a local dev server, run this inside the folder:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy free
### GitHub Pages
1. Create a repository named `Sameer7-s.github.io` on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and enable deployment from the `main` branch and root folder.
4. Wait for the published URL shown by GitHub Pages.
